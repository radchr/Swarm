# Explanatory artifacts

Choose the simplest medium that makes the important relationship inspectable. Follow the user's requested medium when feasible.

| What the reader must see or vary | Useful artifact |
|---|---|
| A static sequence, dependency, or causal path | Small labeled Mermaid diagram or editable SVG |
| Spatial shape, scale, or measured quantities | Accurate drawing or plot with labeled axes and units |
| The result changes with an input or scenario | Interactive HTML model with one or two meaningful controls |
| Movement, timing, or continuous transformation is the lesson | Animation or video; use the local `feynman-manim-composer` for a Manim storyboard when that deliverable is requested |
| Several ideas must be taught in order | Short teaching document or slides with one key claim per step |

Do not add a graphic merely because a topic is complex. A labeled diagram can beat an attractive illustration when the relation is the lesson. An interactive model should let the reader change a cause, see the effect, and compare it with a prediction. Avoid ornamental controls or motion that compete with the concept.

Before building, write down the one claim the artifact must teach, the input or event that reveals it, and the expected visible result. Every label, number, formula, visual encoding, and conclusion is a factual claim: trace it to inspected material or mark it as an illustrative assumption. Keep the editable source as well as the rendered output when creating a file.

Inspect the finished artifact at the intended size. Check that text is readable, the diagram has the intended causal direction, the interaction changes the result correctly, keyboard users can operate controls, and a reduced-motion path preserves the explanation. For a video, inspect representative frames and timing, and verify that the requested output file exists and plays. If only a storyboard was requested, deliver the storyboard and call it a storyboard.

End with one question that asks the reader to use the artifact on a new case. Give feedback or an answer when the artifact is self-contained; let the user answer first in a live coaching exchange.
